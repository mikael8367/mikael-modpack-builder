# Deploy no Render

1. Crie um Web Service usando este repositório.
2. Branch: main.
3. Build Command: npm install
4. Start Command: npm start
5. Health Check Path: /api/status
6. Publique.

Depois do deploy, o Render fornecerá o endereço público do serviço.

O gerador funciona sem CurseForge API Key quando os usuários fornecem URLs públicas diretas dos arquivos.
